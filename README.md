# 선셋 가드 — Frontier Edition v0.8

19세기 서부 개척지를 시작으로 원시 부족, 언데드, 기계 군단, 늪지, 빙결, 화염, 망령, 공허, 최종 전선까지 확장되는 가로형 방치 디펜스 게임입니다. 현재 런타임 그래픽은 외부 캐릭터 이미지 없이 Canvas 픽셀 드로잉을 사용합니다.

현재 작업 브랜치 `gpt/game-overhaul-phase1`에는 **5,000웨이브 캠페인, 7인 영웅, v3 저장, 8부위 장비, 장기 경제, 모바일/PWA, 전투 연출/자동 품질**까지 적용되어 있습니다.

## 실행

폴더형 실행:

```text
index.html
```

단일 HTML 생성:

```bash
python3 build.py
```

기본 출력은 `sunset-guard.html`입니다. CSS/게임 JavaScript는 단일 HTML 내부로 병합됩니다.

PWA 기능은 HTTP/HTTPS에서 `manifest.webmanifest`와 `sw.js`를 사용합니다. `file://` 단일 HTML 실행에서는 Service Worker 등록을 시도하지 않습니다.

## 시작 흐름

앱을 실행하면 바로 전투하지 않고 로딩/타이틀 화면을 표시합니다.

- 신규 진행: `게임 시작`
- 기존 진행: `WAVE N 계속하기`
- 현재 지역과 최고 기록 표시
- START 전까지 전투 루프 정지
- START 후 현재 저장 웨이브 처음부터 재개

## 5,000웨이브 캠페인

- 총 **5,000 웨이브**
- 100웨이브 = Chapter 1개
- 500웨이브 = Act 1개
- 총 50 Chapter / 10 Act
- 10웨이브마다 Elite
- 100웨이브마다 Region Boss
- 500웨이브마다 Act Boss
- WAVE 5,000 = 최종 결전

Act 순서:

1. 개척지의 야수
2. 잊힌 원시 부족
3. 죽은 자의 변경
4. 강철 군단
5. 진홍 늪지
6. 빙결 전선
7. 잿불 황무지
8. 월광 황야
9. 공허의 균열
10. 최후의 지평선

## 7인 영웅

사용자 제공 `sunset-guard-formation-fix-1.html`을 기준으로 화면상 영웅을 다음 7인으로 구성했습니다.

1. **낸시** — 리볼버 원거리
2. **루나** — 다이너마이트 범위 공격
3. **엘로나** — 채찍 탱커
4. **제시** — 기타 지원/회복
5. **줄리** — 황금빛 지원/회복
6. **첼리** — 레버액션 소총
7. **티나** — 스코프 소총

기존 6개 내부 ID는 기존 전투 특성과 v2 저장 호환을 위해 유지하고 줄리만 신규 ID로 추가했습니다.

## 저장 v3 / 구버전 호환

최신 진행 저장 키:

```text
sunset-guard-v3-seven
```

호환 정책:

- v1/v2 기록 → v3 이전
- 최신 진행은 v3에 저장
- 기존 코어 호환용 `sunset-guard-v2` 그림자 저장 동시 생성
- 줄리/v3 전용 장비는 v2 그림자 저장에서 제외
- 기존 `armor/charm`을 신규 장비 슬롯으로 자동 이전
- 손상 저장/백업 로직은 기존 코어와 함께 유지

현재 실제 서버 계정/클라우드 저장은 구현하지 않았습니다.

## 8부위 장비

장비 슬롯:

- 모자
- 한벌 옷
- 신발
- 무기
- 목걸이
- 반지 1
- 반지 2
- 뱃지

기존 `armor`는 `outfit`, 기존 `charm`은 아이템에 따라 `badge` 또는 `necklace`로 이전됩니다.

### 등급과 강화

장비 등급은 5단계입니다.

- 일반
- 고급
- 희귀
- 영웅
- 전설

장비는 **+20**까지 강화할 수 있으며 골드와 `부품`을 사용합니다. Act가 높아질수록 상위 등급 등장 가능성이 증가합니다.

중복 장비는 기존 골드 보상과 함께 부품으로 변환됩니다.

## 장기 성장 / 경제

- 영웅 강화 1 / 10 / 100회
- 마을 강화 1 / 10 / 100회
- Lv.500 장기 성장용 비용곡선 재조정
- 웨이브/Act 복합 적 HP·공격력 성장곡선
- 일반/Elite/Region Boss/Act Boss 차등 장비 드랍
- 웨이브 클리어 골드/보석/부품 보상
- 최초 보스 보상과 반복 보상 분리

### 체크포인트 파밍

100웨이브 단위 보스 전투를 반복할 수 있습니다.

- 실제 본 진행 웨이브는 별도 보존
- 반복 파밍 보상은 본 전선 보상의 55%
- 파밍 종료 시 원래 진행으로 복귀
- 최초 보스 보상은 반복 지급하지 않음

### 일일 / 주간 목표

목표 종류:

- 웨이브 방어
- Elite 이상 격파
- 장비 강화
- 영웅 모집

현재 프로토타입은 브라우저 로컬 날짜를 기준으로 일일/주간 상태를 관리합니다. 실제 서비스에서는 서버 시간 기준 검증으로 교체해야 합니다.

### 업적

- WAVE 100 / 500 / 1,000 / 2,500 / 5,000
- 보스 누적 50회
- 장비 강화 누적 25회
- 영웅 7명 모집

적 행동 유형:

- 신속
- 돌진
- 중장갑
- 괴력
- 원거리
- 지원
- 광폭

- 광역 충격파 + 돌진

- 보호막 + 자가 회복

## 전투 연출 / 성능

Canvas 전투에 절차형 모션과 연출을 추가했습니다.

- 영웅 비전투 bob
- 공격 반동/근접 움직임
- 적 이동 bob
- 총구 화염
- 피격 파편/치명타 강조
- 필살기 빔/링
- 보스 등장 배너
- 화면 흔들림 옵션

**화면 흔들림 기본값은 OFF**입니다.

품질 설정:

- 자동
- 높음
- 중간
- 낮음

자동 품질은 FPS와 전장 부하를 관찰해 파티클/동시 이펙트 수를 조절합니다. 전투 계산은 품질 설정과 분리되어 있습니다.

## 모바일 / PWA

터치 기기는 항상 논리적 가로 화면으로 플레이합니다.

- 실제 기기가 가로면 그대로 가로 표시
- 실제 기기가 세로면 전체 게임 표면을 90° 회전
- 별도의 세로 게임 UI는 사용하지 않음
- 지원 브라우저에서 첫 사용자 입력 후 fullscreen/orientation lock 시도
- 안전영역(safe area) 반영
- 5인 수비대를 한 줄로 고정
- 전투 중 상단 헤더를 제거해 전장 높이 확대
- 영웅/8부위 장비/미션 같은 긴 내용은 팝업 내부만 스크롤

PWA manifest는 `fullscreen`, `landscape`를 요청합니다.

## 테스트

전체 릴리즈 검증 진입점:

```bash
node test-release.cjs
```

이 명령은 먼저 외부 패키지가 필요 없는 구문 검사와 단일 HTML 빌드를 확인합니다.

Playwright까지 설치되어 있으면 다음 회귀 테스트도 순차 실행합니다.

```bash
npm install playwright
npx playwright install chromium
node test-release.cjs
```

개별 테스트:

- `node test-syntax.cjs`
- `node test.cjs`
- `node test-phase3.cjs`
- `node test-phase3b.cjs`
- `node test-mobile.cjs`
- `node test-phase5.cjs`

현재 Phase 1–5 변경 이후의 신규 Playwright 테스트는 GitHub 연결 환경에서 실제 실행하지 않았으므로 **통과했다고 간주하지 않습니다.** 병합 전 실제 Chromium 및 Android/iPhone 실기기 검증이 필요합니다.

상세 검증 범위는 `VALIDATION.md`, 단계별 상태는 `OVERHAUL_ROADMAP.md`를 확인하세요.

## 아직 서버가 필요한 기능

아래 항목은 현재 로컬 프로토타입 범위 밖입니다.

- 실제 계정 인증
- 클라우드 저장
- 서버 권위 재화/모집/드랍
- 결제/영수증 검증
- 계정 삭제/개인정보 처리
- 서버 기반 오프라인 보상

유료 재화나 실제 결제를 연결하기 전에는 현재 클라이언트 로컬 경제를 서버 권위 구조로 전환해야 합니다.
