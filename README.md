# 선셋 가드 — Frontier Edition v0.2

19세기 미국 서부극을 모티브로 한 가로형 방치 디펜스 게임. 사용자가 제공한 여성 총잡이 이미지의 고해상도 반실사 일러스트를 아트 기준으로 사용합니다. 역사 재현 게임은 아니며 의상·무기·적 구성에 판타지 표현이 포함됩니다.

## 실행

전체 폴더의 `index.html`을 브라우저에서 열거나, 별도 제공하는 `sunset-guard.html` 단일 파일을 실행하세요. 폴더 버전은 `assets`, `assets.js`, `game.js`, `style.css`를 함께 유지해야 합니다. 서버나 외부 CDN 없이 동작합니다.

## 변경 사항

- 화면 5시 방향의 원형 메뉴 버튼 → 영웅 / 마을 강화 / 장비 / 전투 배치 / 상점 / 설정 6개 아이콘
- 우측 관리창은 명시적인 목적별 팝업으로 재구성. 이전 스와이프 사이드바 제거
- 보유 영웅을 전투력 내림차순으로 먼저 표시. 이후 미보유 영웅을 흑백으로 표시
- 미보유 영웅 클릭 시 지정 안내 문구 표시, 상세 진입 차단
- 보유 영웅 상세 상단에 누적 강화·장비 착용 현황 표시, 성장 / 장착 장비 / 능력치 탭 제공
- 22종 개별 강화, 마을의 방벽·수리를 별도 마을 강화로 이전. 마을 강화 4종(내구도·수리·피해 감소·보상)
- 탱커는 철퇴 근접 공격. 기본 공격은 주 대상에게 공격력 100%, 탱커의 근접 범위 내 다른 모든 적에게 각각 20%. 지원 버프는 공격 피해에 적용. 탱커는 총알·장전을 사용하지 않음
- 근거리용 철퇴·세이버 추가. 탱커에게 총기를 착용할 수 없도록 무기 유형 검사
- 5인 배치 미리보기와 전투 중 슬롯 교환
- 뽑기 결과 카드, 확률 안내, 10회 이내 미보유 영웅 확정 시스템
- 배경음·효과음 독립 볼륨과 로컬 세션 로그아웃/재개
- 손상 저장 덮어쓰기 방지, 직전 저장 백업, v1 저장 이전, 중복 장비/배치 검증, 다른 창의 저장 충돌 감지
- 고해상도 이미지 자산 로드가 끝난 뒤에만 전투 시작. 저해상도 대체 그래픽을 표시하지 않음

## 아트와 파일

배포 소스 ZIP의 `assets/*.png`는 생성 원본이며, GitHub의 `assets/*.webp`는 **같은 해상도의 무손실 이미지**입니다. GitHub에는 중복 용량을 줄이기 위해 WebP를 저장하고 PNG 원본은 별도 소스 ZIP에 보존합니다. 런타임은 WebP를 사용하며 원본을 축소하지 않습니다. 캐릭터별 해상도와 파일 해시는 `assets/manifest.json`에 기록합니다. 영웅·적·장비·배경 모두 개별 이미지 자산으로 렌더링합니다. 기존 도형 캐릭터/배경 렌더러는 제거했습니다. 작은 메뉴 아이콘과 체력바 등 기능성 UI만 벡터/Canvas를 사용합니다.

19세기 최종 자산만 포함합니다. 중간에 제작한 17세기 복장 이미지는 게임과 배포본에 포함하지 않습니다. 장수연은 사용자 제공 원본을 사용합니다. 다른 이미지들은 내장 이미지 생성 도구로 생성했으며 상세 프롬프트 방향은 `ART_DIRECTION.md`에 기록했습니다.

한글 표시를 위해 Noto Sans KR 일부 글꼴 파일을 동봉하며 해당 라이선스는 `assets/fonts/LICENSE.txt`에 있습니다.

## 저장 / 계정 / 소리

새 저장 키는 `sunset-guard-v2`입니다. v1 기록을 자동 이전하고, 기존 모든 영웅의 방벽/수리 강화는 마을 강화로 합산합니다. 내보낸 v1 저장파일도 불러올 수 있습니다. 다른 파일 위치나 브라우저에서 실행할 때는 저장파일을 먼저 내보내세요.

계정 연동 버튼은 **미지원 상태를 안내**합니다. 인증 서버나 계정 제공자가 연결되어 있지 않습니다. 로그아웃은 로컬 게스트 세션을 종료하며 저장을 삭제하지 않습니다. 서버 로그인·클라우드 저장·결제는 구현되어 있지 않습니다. 실제 돈을 소모하지 않습니다.

Web Audio로 합성한 간단한 배경 선율과 효과음이 포함됩니다. 브라우저 정책에 따라 첫 사용자 클릭 이후 소리가 활성화됩니다. 탭을 숨기거나 로그아웃하면 재생과 전투가 멈춥니다. 오프라인 전투 보상은 없습니다.

## 테스트

`npm install playwright` 후 `npx playwright install chromium`, `node test.cjs`로 실제 브라우저 통합 테스트를 실행할 수 있습니다. 외부 Chromium을 사용하려면 `CHROMIUM_PATH=/path/to/chromium node test.cjs`를 사용하세요.

테스트는 영웅 미보유 잠금, 강화 비용, 탱커 100%/20% 범위 피해·총알/장전 제외, 무기 유형, 마을 강화, 모집 확정, 보스·재도전, 저장 이전·복원, 사운드 설정, 로그아웃, 반응형 팝업을 포함합니다. 구체적인 이번 검증 결과와 제한은 `VALIDATION.md`를 확인하세요.
