# 선셋 가드 — Frontier Edition v0.4

19세기 미국 서부극에서 출발해 원시 부족, 언데드, 기계 군단, 늪지 생물, 빙결 괴물, 화염 생물, 망령, 공허 생명체까지 전선이 확장되는 가로형 방치 디펜스 게임입니다. 현재 런타임 그래픽은 외부 이미지 없이 Canvas 픽셀 드로잉을 사용합니다.

## 실행

전체 폴더의 `index.html`을 브라우저에서 열어 실행합니다. 폴더 버전은 `assets.js`, `phase2-art.js`, `game.js`, `campaign.js`, `phase2-combat.js`, `phase2-ui.js`, `boot.js`, `style.css`, `overhaul.css`를 함께 유지해야 합니다. `python3 build.py`를 실행하면 해당 파일들을 내장한 단일 `sunset-guard.html`을 만들 수 있습니다.

## 앱 시작 흐름

앱을 실행하면 전투 화면으로 바로 진입하지 않고 전용 로딩/타이틀 화면을 표시합니다.

- 신규 플레이어: `게임 시작`
- 기존 플레이어: 저장된 현재 웨이브를 표시하고 `WAVE N 계속하기`
- 최고 도달 웨이브와 현재 지역을 시작 화면에서 확인
- 시작 버튼을 누르기 전에는 전투 루프 정지
- 시작 후 현재 저장 웨이브의 처음부터 방어전 재개

진행 기록은 현재 브라우저의 로컬 저장소에 저장됩니다. 서버 계정과 클라우드 저장은 아직 구현되어 있지 않습니다.

## 5,000 웨이브 캠페인

캠페인은 총 **5,000 웨이브**입니다.

- 100웨이브 = 1개 지역(Chapter)
- 500웨이브 = 1개 대지역(Act)
- 총 50개 Chapter / 10개 Act
- 10웨이브마다 Elite
- 100웨이브마다 Region Boss
- 500웨이브마다 Act Boss
- 5,000웨이브는 최종 결전

현재 Act 구성은 다음과 같습니다.

1. 개척지의 야수
2. 잊힌 원시 부족
3. 죽은 자의 변경
4. 강철 군단
5. 진홍 늪지
6. 빙결 전선
7. 잿불 황무지
8. 월광 황야
9. 공허의 균열
10. 최후의 지평선

각 Act에는 5개 지역과 일반 몬스터 3계열, 엘리트, 보스 이름 및 난이도 메타데이터가 정의되어 있습니다.

## Phase 2 몬스터 / 보스 전투 확장

`phase2-art.js`와 `phase2-combat.js`는 기존 저장 포맷과 영웅 시스템을 바꾸지 않고 적 전투 레이어만 확장합니다.

### 적 행동 유형

- **신속**: 체력을 일부 낮추는 대신 이동 속도 증가
- **돌진**: 주기적으로 짧은 시간 고속 돌진 및 공격 강화
- **중장갑**: 높은 체력과 피해 감소, 느린 이동
- **괴력**: 높은 체력/피해, 느린 이동
- **원거리**: 일정 거리에서 정지한 뒤 수비대를 원거리 공격
- **지원**: 일정 주기로 주변 적 체력 회복
- **광폭**: 체력이 낮아지면 이동 속도와 공격력 증가
- **위상 이동**: 주기적으로 전방으로 순간 이동
- **증식**: 전투당 제한된 수의 소환체 생성

### 보스 패턴

보스는 Act에 따라 세 계열로 나뉩니다.

- 광역 충격파 + 돌진 강화
- 소환체 호출 + 자가 회복
- 보호막 재생 + 자가 회복

500웨이브 Act Boss는 일반 Elite/Region Boss보다 더 높은 방어, 보호막 및 스킬 강도를 갖습니다. 전투 화면에는 보스 이름, 등급, 체력, 보호막이 표시됩니다.

### Act별 픽셀 아트

기존 3종 적 그래픽만 반복하지 않고, 10개 Act별 팔레트와 3종 적 실루엣 조합을 사용합니다. 야수/원시/언데드/기계/늪/빙결/화염/망령/공허/종말 계열을 색상과 장식, 배경 오브젝트로 구분합니다. 외부 PNG/WebP는 사용하지 않습니다.

## 현재 게임 시스템

- 영웅 / 마을 강화 / 장비 / 전투 배치 / 상점 / 설정 6개 관리 메뉴
- 보유 영웅 전투력순 정렬 및 미보유 영웅 잠금 표시
- 영웅 상세: 성장 / 장착 장비 / 능력치
- 영웅별 개별 강화와 마을 강화 4종
- 탱커 철퇴 근접 공격: 주 대상 100%, 범위 내 다른 적 20%
- 근거리 무기 유형 제한
- 최대 5명 수비대 배치 및 전투 중 슬롯 교환
- 영웅 모집 / 장비 상자 / 10회 이내 미보유 영웅 확정
- 배경음 / 효과음 개별 볼륨
- 손상 저장 방지, 백업, v1 → v2 이전, 중복 배치/장비 검증, 다중 창 저장 충돌 감지

## 픽셀 프로토타입

`assets.js`가 기본 영웅/장비 픽셀 도형을 제공하고 `phase2-art.js`가 Act별 적과 전장을 확장합니다. 기존 `assets/`의 HD 이미지 파일은 보관용이며 현재 게임에서 직접 참조하지 않습니다.

기본 여성 총잡이 장수연과 여섯 영웅의 역할 구분, 왼쪽 최대 5명 수비대, 오른쪽에서 진입하는 적이라는 전투 방향은 유지합니다.

## 저장 / 계정 / 소리

저장 키는 `sunset-guard-v2`입니다. v1 기록을 자동 이전하며 내보낸 저장파일을 다시 불러올 수 있습니다. 다른 브라우저나 기기로 옮길 때는 저장파일 내보내기/불러오기를 사용해야 합니다.

계정 연동 버튼은 현재 미지원 안내만 표시합니다. 인증 서버, 클라우드 저장, 결제는 아직 구현되어 있지 않습니다. Web Audio로 간단한 배경음과 효과음을 생성하며 첫 사용자 입력 후 활성화됩니다.

## 테스트

`npm install playwright` 후 `npx playwright install chromium`, `node test.cjs`로 브라우저 통합 테스트를 실행할 수 있습니다. 설정의 독립 테스트 모드에서는 1 / 10 / 100 / 500 / 501 / 1,000 / 1,500 / 2,500 / 4,000 / 5,000 웨이브를 본 진행 저장과 분리해 확인할 수 있습니다.

테스트 코드에는 기존 영웅/장비/저장/보스 로직과 함께 앱 시작 화면, 10개 Act, 50개 Chapter, Phase 2 적 행동 등록, Act Boss 보호막 및 후반 Act 라우팅 검증을 추가했습니다.
