# 선셋 가드 — 서부마을 지키기

서부 마을을 지키는 가로형 방치 디펜스 프로토타입. 외부 라이브러리와 이미지 요청 없이 `index.html` 하나로 실행됩니다.

## 실행

`index.html`을 다운로드한 뒤 Chrome, Edge, Firefox 등에서 열면 자동 전투가 시작됩니다. 모바일은 가로 화면을 권장합니다. GitHub의 파일 보기 화면에서는 게임이 실행되지 않으므로 파일을 다운로드하세요.

## 구현한 게임 시스템

- 여성 총잡이 장수연으로 시작, 최대 5명 배치
- 왼쪽 아군 / 오른쪽 적, 자동 사격·장전·필살기
- 성공 시 다음 웨이브 자동 진행, 실패 시 같은 웨이브 자동 재도전
- 캐릭터별 24종 강화: 공격력, 속사, 장전, 치명타 확률/피해, 탄창, 사거리, 체력, 방어, 회복, 흡혈, 골드, 보스 피해, 광역 피해, 감속, 화상, 기절, 추가 사격, 마을 내구도/회복, 필살기 피해/재사용, 부활, 역전 피해
- 대원 6종 / 원거리·탱커·근거리·지원 4가지 역할
- 캐릭터별 무기·방어구·장신구 장착, 장비 7종, 장비의 단일 소유
- 전투 중 대원 교체와 슬롯 변경, 탱커와 근거리 자동 전방 배치
- 10웨이브마다 중간 보스, 100웨이브마다 메인 보스
- 1–100 동물/황야, 101–200 원시인/협곡, 201–300 좀비/무덤, 이후 난이도를 높여 순환
- 골드/보석 기반 캐릭터 모집과 장비 상자. 실제 결제 없음
- 우측 약 40% 관리창, 스와이프 및 버튼으로 열기/닫기
- 1/2/4배속, 일시정지, 브라우저 자동 저장, JSON 저장파일 내보내기/불러오기
- 본 진행과 분리되는 테스트 모드: 메뉴에서 1, 10, 100, 101, 200, 201웨이브로 이동

## 조작

- 오른쪽 가장자리에서 왼쪽으로 밀기: 관리창 열기
- 관리창을 오른쪽으로 밀기 또는 닫기 버튼: 관리창 닫기
- 아래 수비대 슬롯: 성장 또는 배치 창 열기
- Space: 일시정지/재개, Escape: 창 닫기
- 모집한 캐릭터: 배치 탭에서 원하는 슬롯 번호 선택

## 밸런스와 범위

초기 자원은 600골드, 120보석입니다. 대원 모집은 50보석(각 대원 1/6), 중복은 200골드로 전환합니다. 장비 상자는 250골드(각 장비 1/7), 중복은 120골드입니다. 웨이브와 처치 보상으로 반복 성장할 수 있습니다.

적 체력과 공격력은 웨이브에 따라 증가합니다. 본 버전은 기능 검증용이며 장기 성장 곡선, 가챠 천장, 스킬별 연출, 음향, 최종 캐릭터 아트는 후속 제작 대상입니다. 캐릭터와 배경은 자체 Canvas 도형으로 그린 임시 그래픽입니다. 특정 기존 게임의 이미지나 코드를 사용하지 않습니다.

탭을 닫거나 숨기면 전투는 진행되지 않습니다. 오프라인 보상, 계정 로그인, 서버 저장, 결제, 멀티플레이는 포함하지 않습니다. 저장은 브라우저/파일 위치에 종속될 수 있으므로 파일 이동 전 메뉴에서 저장파일을 내보내세요. 저장 차단 환경에서는 내보내기 기능을 사용하세요.

## 구조

`index.html` 안의 `heroes`, `upgrades`, `items`는 캐릭터/성장/장비 데이터입니다. `stats()`가 능력치를 계산하고 `update()`가 고정 60Hz 전투를 처리하며 `draw()`가 전장을 그립니다. 저장 키는 `sunset-guard-v1`입니다. 테스트 모드는 원래 진행을 메모리에 보존하고 테스트 종료 시 복원하며 로컬 저장을 덮어쓰지 않습니다.

## 검증

Node.js에서 `node test.cjs`로 외부 의존성 없이 핵심 로직 테스트 15개를 실행할 수 있습니다. 자동 웨이브 진행, 중간/메인 보스, 자동 재도전, 100→101 지역 전환, 201 좀비 지역, 배치 중복 방지, 장비 단일 소유와 효과, 개별 강화, 상점 지출, 테스트 모드 복원, 저장 재로드, 잘못된 저장파일 거부를 검증했습니다.

테스트는 DOM/Canvas를 대체한 실행 환경을 사용합니다. 제작 환경에서 브라우저 실행 파일을 설치하지 못해 실제 브라우저 화면·터치·다운로드 대화상자의 통합 검증은 수행하지 못했습니다. 해당 동작은 다운로드한 HTML에서 확인할 수 있습니다.
