# 선셋 가드 — Frontier Edition v0.5

19세기 미국 서부극에서 출발해 원시 부족, 언데드, 기계 군단, 늪지 생물, 빙결 괴물, 화염 생물, 망령, 공허 생명체까지 전선이 확장되는 가로형 방치 디펜스 게임입니다. 현재 런타임 그래픽은 외부 이미지 없이 Canvas 픽셀 드로잉을 사용합니다.

## 실행

전체 폴더의 `index.html`을 브라우저에서 열어 실행합니다. `python3 build.py`를 실행하면 CSS/JS를 포함한 단일 `sunset-guard.html`을 만들 수 있습니다.

현재 주요 모듈:

- `assets.js` — 기본 픽셀 영웅/장비
- `phase2-art.js` — Act별 적/배경
- `game.js` — 기존 전투/성장/저장 코어
- `campaign.js` — 5,000웨이브 캠페인
- `phase2-combat.js` — 적 행동/보스 패턴
- `phase2-ui.js` — 1~5,000 독립 QA 점프
- `phase3-equipment-pre.js` — v3 장비 스키마 사전 변환
- `phase3-reference.js` — 7인 영웅/v3 저장/묶음 강화/체크포인트
- `phase3-equipment.js` — 8부위 페이퍼돌 및 v2 역호환 저장
- `phase3-polish.js` — 7인/5,000웨이브 안내 문구 정리
- `boot.js` — 모바일 게임형 시작 화면

## 앱 시작 흐름

앱을 실행하면 바로 전투하지 않고 로딩/타이틀 화면을 표시합니다.

- 신규 플레이어: `게임 시작`
- 기존 플레이어: `WAVE N 계속하기`
- 최고 도달 웨이브/현재 지역 표시
- START 전까지 전투 정지
- 시작 후 저장된 현재 웨이브부터 재개

## 5,000 웨이브 캠페인

- 총 **5,000 웨이브**
- 100웨이브 = Chapter 1개
- 500웨이브 = Act 1개
- 총 50 Chapter / 10 Act
- 10웨이브 Elite
- 100웨이브 Region Boss
- 500웨이브 Act Boss
- 5,000웨이브 최종 결전

Act: 개척지의 야수 → 잊힌 원시 부족 → 죽은 자의 변경 → 강철 군단 → 진홍 늪지 → 빙결 전선 → 잿불 황무지 → 월광 황야 → 공허의 균열 → 최후의 지평선.

## 7인 영웅 체계

첨부된 `sunset-guard-formation-fix-1.html`을 참고해 화면상 영웅 구성을 다음 7인으로 전환했습니다.

1. **낸시** — 리볼버 원거리
2. **루나** — 다이너마이트 원거리/범위
3. **엘로나** — 채찍 탱커
4. **제시** — 기타 지원/회복
5. **줄리** — 황금빛 지원/회복
6. **첼리** — 레버액션 소총 원거리
7. **티나** — 스코프 소총 원거리

기존 코어의 6개 내부 ID는 전투 특성/기존 저장과의 호환을 위해 유지하고, 줄리를 7번째 신규 영웅으로 추가했습니다. 줄리는 주기적으로 체력이 낮은 수비대원을 회복하고 마을 내구도를 소폭 보조합니다.

## 저장 v3 / 구버전 호환

신규 기준 저장 키는 `sunset-guard-v3-seven`입니다.

- v1/v2 기록을 v3으로 이전
- v3가 실제 최신 진행 기록
- 동시에 `sunset-guard-v2` 호환 그림자 저장을 생성
- 기존 로더가 먼저 실행되는 구조에서도 다음 단계 v3 로더가 기록을 복원할 수 있도록 설계
- 줄리 및 v3 전용 장비는 v2 그림자 저장에서는 안전하게 제외

서버 계정/클라우드 저장은 아직 연결하지 않았습니다.

## 8부위 장비

영웅 장비는 첨부본과 동일한 8부위 방향으로 확장했습니다.

- 모자
- 한벌 옷
- 신발
- 무기
- 목걸이
- 반지 1
- 반지 2
- 뱃지

기존 `armor`는 `outfit`, 기존 `charm`은 아이템에 따라 `badge` 또는 `necklace`로 이전됩니다. 구형 v2 그림자 저장에는 다시 `armor/charm`으로 역변환합니다.

신규 장비 예시: 황혼의 개척자 모자, 사막길 장화, 결투가의 반지, 황혼의 반지. 영웅 전용 무기로 루나의 다이너마이트, 제시의 기타, 줄리의 지팡이를 추가했습니다.

## 성장 / 장기 진행

- 영웅 강화 `1 / 10 / 100회` 선택
- 마을 강화 `1 / 10 / 100회` 선택
- 전투 배치 `추천 배치` 기능
- 최초 Elite / Region Boss / Act Boss 클리어 보너스
- 100웨이브 단위 체크포인트 저장
- 체크포인트는 본 진행을 바꾸지 않는 독립 연습 모드로 진입 가능
- 설정에서 현재 전선, 최초 보스 기록, 누적 웨이브 클리어 확인

## Phase 2 적/보스 전투

적 행동 9종: 신속, 돌진, 중장갑, 괴력, 원거리, 지원, 광폭, 위상 이동, 증식.

보스 패턴 3계열:

- 광역 충격파 + 돌진 강화
- 소환체 + 자가 회복
- 보호막 재생 + 자가 회복

500웨이브 Act Boss는 일반 Elite/Region Boss보다 더 높은 방어/보호막/스킬 강도를 가집니다.
