# Enemy run-cycle sprites

Generated 8-frame horizontal run-cycle sprite sheets used by `monster-motion.js`.

- `boar-run.webp`
- `wolf-run.webp`
- `cat-run.webp`
- `caveman-run.webp`
- `zombie-run.webp`

Each sheet uses 8 cells, 220×200 per frame, with feet aligned to a common ground anchor. Combat math remains in the existing game modules; this folder is rendering-only.
